Sauvegarde et identité

Votre compte

Configurez Supabase pour créer un compte accessible à vos amis et synchroniser votre progression entre appareils. L’URL du projet et la clé anon publique peuvent être utilisées dans le navigateur si les règles RLS sont activées.

Configuration nécessaire dans Supabase

Créez un projet, puis exécutez le SQL fourni ci-dessous dans SQL Editor. Activez l’authentification par e-mail et ajoutez l’URL de votre site GitHub Pages aux URL autorisées. Pour que vos amis n’aient pas à saisir ces réglages, renseignez l’URL du projet et sa clé publique dans SUPABASE_PROJECT dans index.html avant publication. Seules les clés publiques sont acceptées ici ; ne mettez jamais une clé service_role dans cette page.
